Вход через свой Twitch (один раз настроить)
  1. Открой dev.twitch.tv/console/apps → «Register Your Application» (на аккаунте должна быть включена 2FA).
  2. OAuth Redirect URL — вставь точно это:
  3. Category: Chat Bot, Client Type: Public. Скопируй Client ID и вставь сюда:
Твитч не принимает адрес вида file://. Запусти сайт локально: открой папку с файлом в терминале → python -m http.server 8000 (на Windows py -m http.server 8000) → открой http://localhost:8000/twitch-tools.html. Или залей файл на GitHub Pages / Netlify и используй их адрес в Redirect URL.
