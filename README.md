# 🎯 MAGA STREAM ROULETTE (Рулетка для Twitch)

Интерактивная рулетка / колесо фортуны для Twitch-стримера, разработанная специально под **прокачки аккаунтов**, **аукционы за 1 балл канала** и **розыгрыши**.

---

## ✨ Возможности

1. **Режим «Прокачки» (Сбор по кодовому слову в чате):**
   * Стример задает любое кодовое слово (например, `го`, `+`, `прокачка`).
   * Включает таймер сбора (30 сек, 60 сек, 120 сек или ручной).
   * Подключается напрямую к открытому Twitch IRC WebSocket без регистрации и токенов.
   * Автоматически добавляет зрителей в колесо при отправке слова.
   * Защита от дублей (1 зритель = 1 билет).

2. **Режим «Аукцион» (Баллы канала / Channel Points за 1 балл):**
   * Подключение через официальный **Twitch EventSub WebSocket**.
   * Авторизация стримера в 1 клик через Twitch.
   * Выбор конкретной награды из списка наград канала (например, награды за 1 балл).
   * Автоматическое мгновенное добавление зрителя при выкупе награды.
   * Встроенная кнопка «Тест: Купить за 1 балл» для проверки без зрителей.

3. **Колесо фортуны со звуком и физикой:**
   * Плавная физическая анимация вращения с затуханием (Cubic-Bezier Ease-Out).
   * Процедурные звуки тиканья зубьев колеса при прокрутке (Web Audio API, без битых ссылок).
   * Победный фанфар и взрыв конфетти на весь экран.
   * Кнопка автоматического или ручного исключения победителя из следующего раунда.
   * Перемешивание (Shuffle), ручное добавление/удаление или вставка списка ников пачкой.

4. **Интеграция с OBS (Оверлей для стрима):**
   * Чистый оверлей с **100% прозрачным фоном** (`?obs=true`).
   * Синхронизация в реальном времени: стример крутит колесо на мониторе в панели управления — в OBS оно автоматически крутится на стриме!

## 🚀 Быстрый запуск

### 1. Запуск приложения
```bash
npm run dev
```
Откройте в браузере: **http://localhost:5173**

### 2. Подключение виджета в OBS
1. В OBS добавьте новый источник: **Браузер** (Browser Source).
2. В поле URL вставьте:
   ```
   http://localhost:5173/?obs=true
   ```
3. Задайте размер (например, **800x800** или **1000x1000**).
4. Поставьте галочку **«Завершать работу, если не отображается»** по желанию.
5. Готово! Колесо отображается на стриме с прозрачным фоном.

## 🛠 Технологии
* **Frontend:** React 19, Vite, Tailwind CSS v4, Lucide Icons, Canvas-Confetti.
* **Аудио:** Native HTML5 Web Audio API (синтез звуков в реальном времени).
* **Сетевой уровень:** Native WebSocket Twitch IRC (`wss://irc-ws.chat.twitch.tv`), Twitch EventSub WebSocket (`wss://eventsub.wss.twitch.tv/ws`).
